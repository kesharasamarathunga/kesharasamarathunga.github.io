Privacy Policy

This application does not collect, store, or process any personal data from any users. It does not have public users, does not offer a login, and does not read data from any Facebook profiles.

The application uses the Facebook Graph API only to publish content (images and captions) to a Facebook Page owned and administered by the application owner. It does not read, collect, or share information about any other person or account.

Data Sharing

No data is shared with third parties, because no user data is collected.

Data Retention and Deletion

As no user data is collected, there is no user data to retain or delete. If you believe this application holds any data about you and wish to have it removed, contact us using the email below and it will be addressed promptly.
